# Kvant — Інтернет-магазин цифрової техніки

Сучасний вебсайт інтернет-магазину смартфонів та гаджетів з інтерактивним каталогом, кошиком, списками обраного та порівняння.

## Структура проєкту

* `index.html` — головна сторінка та структура SPA (Single Page Application)
* `style.css` — стилі, темна тема UI та адаптивний дизайн
* `script.js` — логіка каталогу, фільтрації, кошика, модальних вікон та локального сховища

## Технології

* HTML5
* CSS3 (Flexbox & Grid, CSS variables)
* JavaScript (ES6+, LocalStorage)
* Font Awesome 6.4.0 (векторні іконки)
* Google Fonts (Plus Jakarta Sans)
